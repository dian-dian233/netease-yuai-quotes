# 雨爱 · 语录轮播

杨丞琳《雨爱》主题的雨夜语录轮播页。纯前端单文件，**零依赖、零外部资源、零密钥，离线双击即可打开**。

打开地址：**https://dian-dian233.github.io/netease-yuai-quotes/**

## 它长什么样

- 近黑蓝深色底 + 四周暗角，冷光缓慢呼吸（11s 一圈，alternate）
- 细斜雨线在下，落在文字**后面**（canvas 绘制，按屏幕面积自适应 55~300 条）
- 中间一张黑胶缓慢自转（64s 一圈），带一道极淡的冷色扫光
- 语录 12 条，7 秒一换：先淡出上浮 + 模糊，再自下浮起 + 去模糊（每行错开 110ms）
- 底部细进度条 + 可点击圆点 + `03 / 12` 计数

## 交互

| 操作 | 行为 |
| --- | --- |
| 左 / 右箭头按钮 | 上一句 / 下一句 |
| 键盘 `←` `→` | 上一句 / 下一句 |
| 键盘 `空格` | 下一句 |
| 键盘 `Home` / `End` | 首句 / 末句 |
| 手机左右滑动 | 上一句 / 下一句（阈值 42px，且横向位移大于纵向 1.3 倍才触发，不干扰竖向滚动） |
| 点圆点 | 跳到该句 |
| 鼠标移到页面上 | 暂停自动轮播，移开继续 |
| 切走标签页 | 暂停；切回来继续，进度不跳变 |

## 适配

- 字号 `clamp(1.28rem, 4.55vw, 3rem)`，窄屏自动降行高与字距
- 断点：`560px` 隐藏键盘提示、圆点计数移位；`380px` 再压字号；横屏矮屏（`max-height:520px`）单独排版
- `viewport-fit=cover` + `env(safe-area-inset-*)`：刘海屏/小白条不遮内容
- 触控目标：圆点视觉 6px，但 `::after` 外扩到约 28px 命中区

## reduced-motion 降级

系统开启「减少动态效果」时（`prefers-reduced-motion: reduce`）：

- 雨、旋转、呼吸光全部关闭
- 语录切换退化为 0.22s 纯透明度变化，无位移无模糊
- 自动轮播继续（换文字不算运动），进度条隐藏

## 部署方式

已用 GitHub Pages（`main` 分支、根目录）发布，无需构建。

自己重建的两种办法：

1. **网页操作**：仓库 → Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save，等 1 分钟。
2. **命令行**：
   ```bash
   gh api -X POST repos/dian-dian233/netease-yuai-quotes/pages \
     -f 'source[branch]=main' -f 'source[path]=/'
   ```
